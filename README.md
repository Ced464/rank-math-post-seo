# Rank Math Post SEO Skill

A portable Agent Skill for researching, drafting, optimizing, and auditing WordPress posts with Rank Math SEO.

## Files
- `SKILL.md`: core instructions and output contract.
- `references/seo-rules-and-sources.md`: rationale and links to Rank Math, Google Search Central, Agent Skills specification, and an illustrative community discussion.

## Install
Copy the entire `rank-math-post-seo` folder into the skills directory supported by your AI agent. Keep the folder name `rank-math-post-seo` aligned with the `name` in the YAML frontmatter. If your agent supports only a standalone `SKILL.md`, use that file; the core rules are included there, while the references file provides source detail.
